# Prototype 四球球路分析

用于固定机位的手机离线视频。四球依次发射，每球手动指定起始时刻和球中心，程序自动跟踪这一段飞行；无需训练模型。适合射击调试，未用实拍视频验证前不可把自动轨迹当作准确测量。

## 启动

macOS 双击本目录的 `start.command`。首次启动会创建本目录的 `.venv` 并安装依赖，需要联网。之后在浏览器打开 http://127.0.0.1:8501 。关闭终端或按 Ctrl+C 停止。服务只监听本机，视频不会上传云端。

也可以在仓库根目录运行：

```sh
./tools/shot_analyzer/start.command
```

若端口被占用，在本目录手动选择另一个端口：

```sh
.venv/bin/python -m streamlit run app.py --server.headless true --server.address 127.0.0.1 --server.port 8502 --browser.gatherUsageStats false
```

## 拍摄与跟踪

1. 固定手机，完整拍到出球口和目标。推荐原始高帧率视频；手持跟拍、画面运动、严重模糊、球被长时间遮挡都可能导致错跟。
2. 导入视频，按发射先后设置四个区间。开始帧选在球刚离开发射器时，结束帧选在到达目标、碰撞或反弹之前。时间窗口允许重叠。
3. 在每球的起始帧拖动 X/Y 坐标，使十字对准球中心，框中包含球和少量周围背景。普通视频可搜索每帧 100 px；若球过快需扩大。
4. 点击跟踪。不同球按人工指定的发射次序编号，不声称自动识别发射事件。跟踪采用局部预测和模板外观匹配；遇到同色物体或交叉球路可能串轨。
5. 必须核对叠加图。可在坐标表添加漏点、删除错点或修改 x/y/t。每个球的时间唯一且递增。显示线段会跨越缺帧连接，连接段不表示已观测到球；匹配分数也不是准确率。
6. 指定目标入口中心像素坐标。结果中的目标处偏高 px 为正代表偏高；它只表示通过画面竖线的二维差，不能判断侧向偏出或实际命中。

## 角度与速度建议

- 无标定：只输出二维轨迹、画面高低偏差和定性试验方向。
- 物理估算需要固定侧拍，镜头近似垂直于飞行平面，并使用同平面的已知长度标定。不要把场地远端地板长度直接用于近端球路；明显透视需要先做相机标定/重投影，本版本不提供三维恢复。
- 速度是跟踪开始时的球速，只有开始帧紧邻出球口才可近似视为出射速度。投影角也不能直接等同于发射机构机械俯仰角或舵机位置。
- 慢动作导出视频需填写“文件秒 / 实际秒”：如真实 1 秒被导出为 8 秒，填 8。原始 240 fps 文件若仍以真实时间播放，填 1。
- 仅在轨迹残差小、重力方向加速度基本合理、目标时间接近可见区间时计算简化抛体方案。模型忽略空气阻力、旋转升力与球的变形，计算值是下一次试验的参考。
- 分别给出固定角度所需球速，以及固定球速可达的角度。两种方案二选一试验，不能同时更改。RPM 按球速与轮速近似成比例估算，首轮试验变化限制为 3%；这不是标定好的球速—轮速模型。
- 无舵机角度标定表，不输出虚构的舵机位置值。

## 飞轮 PIDF

在“飞轮 PIDF 诊断”导入 CSV，必需列：

```csv
time_s,target_rpm,actual_rpm
0.00,5000,0
0.02,5000,320
```

至少 12 条严格递增时间记录，建议每 20 ms 采样。一次只分析一个恒定目标转速片段，转速使用绝对值。`time_s` 是机器人日志的秒数。填写四个出球在日志中的时刻；视频与日志不会自动同步。

输出：目标/实测转速曲线、末段偏差、超调、波动、每球后的最低转速和恢复时间。恢复需连续至少 0.2 s 处于容差内；下次射击之前没有恢复则报告 null，而不是 0。每次恢复窗口最长 1.5 s。

球路视频不能区分 P/I/F 配置、输出饱和、电压下降、打滑或送球负载，因此程序只给出检查和受控调参方向，不自动生成“最佳 PID”。建议同时记录当前 PIDF、motor output、电压及出球事件。当前仓库 Shooter 已提供右侧转速反馈，但主 TeleOp 的功率档位并未使用该转速闭环；先确认实际运行的是哪种控制模式。

## 输出和数据

可下载轨迹叠加 PNG、手工修正后的 CSV、每球分析 JSON 与转速诊断 JSON。上传视频保存在系统临时目录 `prototype-shot-analyzer`，不写入仓库；退出后如需释放空间可手动删除该目录。修改视频或起点后需重新跟踪。

## 验证

```sh
cd tools/shot_analyzer
.venv/bin/python -m unittest -v test_analysis.py
```

覆盖模拟四次发射视频、物理速度与角度解、异常点、缺失标定与转速恢复。模拟测试不代表实际手机视频跟踪准确率。

实现参考：[OpenCV 模板匹配](https://docs.opencv.org/4.x/d4/dc6/tutorial_py_template_matching.html)。
